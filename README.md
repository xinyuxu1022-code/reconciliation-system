# 跨境运营费用对账系统

一个面向跨境运营场景的对账与审计管理系统，支持供应商费用核对、凭证校验、异常追踪与数据可视化分析，帮助运营团队提升对账效率和风险控制能力。

## 项目概览

- 面向跨境供应链运营场景
- 支持多供应商、多币种费用对账
- 覆盖凭证完整性校验、异常识别、状态跟踪
- 提供管理端可视化分析面板
- 适合展示数据治理、流程标准化与运营决策支持能力

## 核心功能

- 供应商费用对账
- 多币种汇率与历史快照管理
- 凭证完整性校验
- 异常订单、待处理单据追踪
- 运营看板与趋势分析
- 角色分离：司机 / 供应商 / 总部管理端

## 技术栈

- HTML / CSS / JavaScript
- 前端交互式仪表盘
- 本地模拟数据
- 数据可视化展示
- 响应式页面设计

## 项目亮点

- 结合真实业务场景设计对账流程
- 通过清晰的仪表盘展示供应商对账情况
- 支持对账规则扩展与流程标准化
- 可用于作品集展示 / 面试介绍 / 项目汇报
